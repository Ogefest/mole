# Projects

Work too large to be a line in [TODO.md](../../TODO.md) and too early to be an
[ADR](../adr/). A project file says what is being built, why, in what order, and
how anyone will know a phase is finished.

A project is not a record of a decision. When one of these produces a decision
worth keeping — a library chosen, an extension point reshaped — that decision
gets its own ADR and this file links to it. When the work is done, the project
file goes, and [DONE.md](../../DONE.md) carries the account of what happened.

One file per project, named for the thing rather than numbered: projects are few
and are meant to end.
